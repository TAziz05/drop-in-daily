# Drop-In Daily – build folder

Everything that makes the game lives here. Run `npm install` once, then `npm run build`.
That writes `../index.html` (the website) and `../daily/*.json` (each day's Daily Drop for the Discord bot).

## Where questions live
- `seasons-ch1-2.js`, `seasons-ch3-7.js` – one group per season (`id` like `C7S4`).
- Topic groups: `modes.js`, `events.js`, `loot.js`, `easy.js`, `bigpatch.js`, `words.js`, `chapters.js`, `lore2.js`, `sprites2.js`, `connections.js`, `odd.js` (generated by `gen-odd.js`).
- `locations.js`, `locations2.js` – Where Am I? clues (`LOCS3` = landmarks).
- New files must be added to the list in `build-data.js` (the `new Function(...)` line).

Group format: `SEASONS.push({id,ch,name,sub,page|url,qs:[[tier,question,answer,[3 wrong],explanation,source],...]})`
Tiers: `e` Easy, `m` Medium, `h` Hard, `x` Impossible. `G` = Fortnite Wiki base URL, `W` = Wikipedia base URL.

## Rules
- Lore and mode facts come only from the Fortnite Wiki (fortnite.weirdgloop.org; fandom is OK). Wikipedia only for real-world facts. fortnite.gg is allowed for weapon stats. Posts on X are cited as plain text like `Mark Rein (@MarkRein) on X, Aug 6, 2026`.
- Every question links its source. Never remove old questions unless they're wrong.
- Options in one question use a consistent naming style. Answers must not be guessable from the season label.
- Season-group questions say "this season" for their own season. Anything that changes over time (stats, follower counts) says "as of <month year>".
- Don't use questions about rumors or leaks.

## Versions
`versions.json` holds `[label, date, note]`. Major change `vX.00`, minor `vX.10`, small additions or fixes `vX.01` (add 0.01 to the last label: v12.29 → v12.30). The page shows the newest label and the update count.

## Publishing
Work goes on the `not-live-till-night` branch. The "Midnight release" GitHub Action merges it into `main` at midnight Eastern.
Only push straight to `main` if Towsif asks for it.

## Days in play never change
`pin.js` (part of `npm run build`) reads the live site from `origin/main` and freezes yesterday's, today's and tomorrow's
questions (Eastern) exactly as players see them now. New questions only start appearing in daily sets from the day after
tomorrow, so a publish (even a late one) never swaps a day someone has already played. Other modes use new questions right away.
